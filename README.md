# 不爽即录 — 交互原型

基于需求文档《系统不爽即录.docx》，页面视觉与布局参考同级目录 `listing信息变动通知/listing信息变动通知.html`。

## 打开方式

用浏览器直接打开：

`不爽即录.html`

## 原型范围（对应文档 MVP / P1）

| 能力 | 说明 |
|------|------|
| ERP 嵌入示例 | 左侧菜单进入 **listing信息变动通知**，简化版成本价变动列表 |
| 不爽入口 | 右下角悬浮按钮「点这里说不爽」；快捷键 `Ctrl+Shift+B` |
| 5 秒反馈 | 四快捷标签 + 可选文字；自动展示采集上下文（URL、模块、最近点击等，原型为模拟） |
| 防滥用 | 每用户每日最多 5 次（localStorage） |
| 产品看板 | **不爽即录看板**：KPI、7 日趋势、分类分布、AI 聚合列表、优先级 P0/P1/P2、详情与改分类 |
| 导出 | 聚合结果导出 CSV（Excel 可打开） |

数据保存在浏览器 `localStorage`，无后端。
